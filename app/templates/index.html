IDP Validation App

Validate IDP extraction vs expected ground truth. Fuzzy matching (REQ-1) and manual overrides (REQ-2).

AssistRx Test Suite Extract & Edit (PDF → ground truth) Saved Ground Truth Upload Form New run Runs Expected data (JSON)

Quick start

  1. AssistRx Test Suite – Open /suite for reference documents (enrollment, insurance, copay). Set ground truth per PDF, run IDP, and see field-level success % on the dashboard.
  2. Extract & Edit – Upload a PDF enrollment form (or image), run IDP extraction, correct the extracted values, and save as ground truth. Then load that saved document into New run as Expected.
  3. Upload Form – Send a form to your MuleSoft IDP Document Action (region, org, action ID, version); view and copy the JSON response.
  4. New run – Paste expected (correct) JSON and IDP result JSON in the two panels, then compare. Or use “Load from saved” to pull in a document you saved from Extract & Edit.
  5. Runs – View history with success rate per run. Click a row to see field-by-field comparison (expected ↔ ✓/✗ ↔ IDP).
  6. Overrides – Mark any field as correct or incorrect; clear overrides as needed.
  7. Reset – Clear all runs and metrics from the Runs page (expected data is kept).
