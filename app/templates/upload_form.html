Where to find these in Anypoint Platform
  • Platform (domain) – Choose Staging (US) if your org is on the staging environment and you log in at https://stgx.anypoint.mulesoft.com. Choose Production (US) for anypoint.mulesoft.com, or EU for eu1.anypoint.mulesoft.com. This is the “URL” — we use it to call the right token and IDP endpoints; you don’t type a URL.
  • Region – If you use Production or Staging (US), use us-east-1. If you use EU platform, use eu1.
  • Organization ID – Access Management → Business Groups → select your group → Settings tab shows the Business Group ID. Or open API Manager and check the URL: the value after organizations/ is your Org ID (e.g. 4500658a-7637-4fcf-bc7d-51d1feb28edb).
  • Action ID – After you publish a Document Action from IDP, it appears in Anypoint Exchange as an API. Open that asset in Exchange; the API specification or asset details show the action ID (a UUID). You can also open the API in the API portal and use the endpoint path: .../actions/{actionId}/versions/....
  • Version – The version you set when publishing (e.g. 1.0.0). Shown in the IDP publish dialog and in the Exchange asset. Update this field when you republish with a new version.
  • Client ID & Client Secret – Must come from a Connected App with scope "Execute Published Actions" (see below). The Client ID/Secret on the main Access Management screen are organization API credentials, not the same — IDP requires a Connected App (see "Do I need a Connected App?" below for steps). To create one: Access Management → Connected Apps → Create App; name it, choose type “App acts on its own behalf (client credentials)”, add scope “Execute Published Actions”, save. Copy the Client ID and Client Secret (you must be at the root organization to see Connected Apps).
Do I need a Connected App? How to create one for IDP

Yes. The IDP API requires a Connected App with the scope Execute Published Actions. The credentials on the main Access Management page are for your organization's general API access; they are not the same as a Connected App. Follow these steps (you need Organization Administrator or similar):

  1. Log in to Anypoint Platform (e.g. https://stgx.anypoint.mulesoft.com for Staging).
  2. Go to Access Management → Connected Apps. (If you don't see it, you may need to be at the root organization — switch business group to the top-level org.)
  3. Click Create App and enter a name (e.g. "IDP Validation App").
  4. For Type, select App acts on its own behalf (client credentials).
  5. Click Add Scopes. In the scopes list, search for or select Execute Published Actions (under IDP). Click Add Scopes, then apply to the business groups/environments you need and click Next until you can click Save.
  6. After saving, the app shows a Client ID and Client Secret. Copy both and paste them into the form above (or use Save credentials to store them in this browser).
